## Environment constraints

The admin machine for this project has no `cmd`, no admin rights, and nothing added to `PATH`.
Prefer PowerShell built-ins and existing local files — do not assume global CLIs are installed.

## External services needed

- Firebase Firestore project: `ggowcpredictor`
- API-Football key from API-Sports, stored only in Apps Script or another trusted backend
- Google Apps Script / `clasp` deployment for scheduled score sync

## Live results worker

```bash
npm install
set FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
npm run live-sync
```

See [Introduction → Live results worker](/index#live-results-worker) for the full environment
variable reference.
