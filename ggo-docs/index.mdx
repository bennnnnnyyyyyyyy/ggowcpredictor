## Goal

Employees log in with a username and secret code, predict individual match scores, see official
group tables synced from Supabase, and compete on a shared leaderboard. Real results and official
group standings are synced automatically from trusted football data sources — an admin does not
manually enter match results.

## Current architecture at a glance

- `index.html` — the static app shell
- `style.css` — the visual system
- `scripts/app.js` — the browser app logic loaded by `index.html`
- `src/` — Google Apps Script backend code deployed by `clasp` (run-time client backup, **not** the browser entrypoint — this naming trips people up)
- `2026/worldcup.json` and related files — local fixture seed data from openfootball
- **Supabase** — primary datastore for users, fixtures, predictions, results, leaderboard, and official group standings
- **Cloudflare Worker** (`workers/live-results.js`) — trusted backend for score syncing, group standings syncing, and leaderboard maintenance
- **Firestore** — legacy backup/fallback data source for older flows (being phased out, see [Architecture](/architecture))

## Live results worker

Apps Script stays in place for fixture seeding, but live scores/results run through the Node
worker:

```bash
npm install
set FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
npm run live-sync
```

<AccordionGroup>
  <Accordion title="Environment variables">
    - `FIREBASE_PROJECT_ID` — defaults to `ggowcpredictor`
    - `worldcup26.ir` — primary live-source used by the worker
    - `ZAFRONIX_URL` — overrides the live results endpoint
    - `LIVESCORE_API_KEY` / `LIVESCORE_API_SECRET` — enable the backup live source
    - `ZAFRONIX_API_KEY` — enables the secondary fallback source
    - `SEED_TOKEN` — protects manual sync endpoints such as `/seed`, `/sync-scores`, and `/admin/sync-standings`
    - `LIVE_SYNC_CRON` — defaults to `*/5 * * * *`
    - `LIVE_SYNC_RUN_ON_START=false` — skips the first immediate sync
    - `LIVE_SYNC_DRY_RUN=true` — logs matches without writing Firestore
  </Accordion>
  <Accordion title="Alternate credentials">
    If `GOOGLE_APPLICATION_CREDENTIALS` is already configured, the worker can use ADC instead of a
    JSON service account.
  </Accordion>
</AccordionGroup>
